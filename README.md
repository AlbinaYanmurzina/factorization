## О проекте

Выпускная квалификационная работа по теме: реализация и сравнительное исследование алгоритмов факторизации целых чисел.

Проект представляет собой веб-приложение для интерактивного изучения и сравнения классических алгоритмов факторизации из учебного пособия проф. Ишмухаметова Ш.Т.

**Цель работы:** программная реализация и сравнительный анализ эффективности экспоненциальных алгоритмов (методы Полларда) и субэкспоненциального метода квадратичного решета (алгоритм Диксона).

## Реализованные алгоритмы

### Глава 3. Простые алгоритмы факторизации

| Ключ API | Алгоритм | Раздел | Сложность |
|---|---|---|---|
| `pollard_rho` | ρ-метод Полларда | 3.4 | O(n^{1/4}) |
| `pollard_p1` | (p−1)-метод Полларда | 3.2 | O(n^{1/2}) |

### Глава 6. Метод квадратичного решета

| Ключ API | Алгоритм | Раздел | Сложность |
|---|---|---|---|
| `qs_basic` | Алгоритм Диксона (QS Basic) | 6.1 | L[1/2, c] |

**Примечание:** L[1/2, c] = exp(c · √(ln n · ln ln n)) — субэкспоненциальная сложность.

## Возможности приложения

### 1. Главная страница
- Теоретическое описание алгоритмов

## Установка и запуск

```bash

cd factorization

```

### 2. Создание и активация виртуального окружения



## Примеры использования

### Быстрый тест на малых числах

```python
# Запустите в Python после установки зависимостей
import requests

numbers = [8051, 10403, 15770708441]
algorithms = ["pollard_rho", "pollard_p1", "qs_basic"]

for num in numbers:
    for algo in algorithms:
        response = requests.post(
            "http://127.0.0.1:8000/api/factorize",
            json={"number": str(num), "algorithm": algo}
        )
        data = response.json()
        print(f"{algo}: {num} = {' × '.join(data['factors'])} ({data['time_ms']:.2f} мс)")
```

## Результаты исследования

### Экспериментальные данные

Тестирование проводилось на полупростых числах (произведение двух простых чисел) различной разрядности:

- **ρ-метод Полларда:** эффективен до 40-50 бит, O(n^{1/4})
- **(p-1)-метод Полларда:** зависит от гладкости (p-1), O(n^{1/2})
- **Алгоритм Диксона (QS Basic):** субэкспоненциальный, эффективен на числах 30-40 бит

### Выводы

1. Экспоненциальные алгоритмы (Полларда) просты в реализации и эффективны на малых числах
2. Субэкспоненциальный алгоритм (квадратичное решето) имеет лучшую асимптотику, но требует больше памяти
3. Выбор алгоритма зависит от размера числа и структуры его делителей
